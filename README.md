# SaaS Customer Churn & Retention Analysis

![SaaS 客戶流失與留存分析封面](./image/saas_image1.JPG)

> 客戶為什麼離開？哪些訊號值得優先調查？本專案從 SaaS 訂閱資料出發，將客戶流失問題轉化為可探索、可討論的資料洞察。

## 專案背景

客戶流失會影響 SaaS 企業的續約與經常性收入。本分析以 2023–2024 年的客戶資料為基礎，先掌握整體流失與時間變化，再進一步探索不同客戶族群、訂閱方案、客服體驗及產品功能使用情形，尋找值得後續驗證的風險訊號。

![專案分析前言：分析 SaaS 客戶流失的商業背景](./image/saas_image2.JPG)

分析的起點是理解客戶流失對 SaaS 經常性收入與企業成長的影響，並探索流失是否與客戶服務品質、滿意度或產品方案等面向相關。這些面向是調查線索，不預設任何單一因素就是流失原因。

## 從商業問題到分析問題

![分析問題：客戶流失比例與時間趨勢](./image/saas_image3.JPG)

因此，分析先聚焦兩個問題：整體客戶流失比例為何？流失是否隨時間出現變化？掌握流失規模與趨勢後，再進一步比較不同客群和使用經驗，尋找值得深入驗證的方向。

## 分析流程

1. **整理資料與建立關聯**：以 SQL 檢視帳戶、訂閱、流失事件、功能使用與客服工單資料，透過帳戶及訂閱識別碼串接分析所需資訊。
2. **建立分析視角**：使用 BigQuery SQL 建立整體及月度流失指標，並按國家、產業、產品方案、客服經驗與功能使用情形切分觀察。
3. **呈現與探索**：在 Looker Studio 儀表板彙整關鍵指標與趨勢，讓使用者能由整體概況逐步探索不同客群。

## 儀表板與初步觀察

![Looker Studio 客戶流失總覽儀表板](./image/saas_image4.JPG)

儀表板先呈現整體客戶流失概況，再以月度趨勢圖協助定位值得追查的時間區段：
- 帳戶概況顯示共有 **500 位客戶**，其中 **110 位標記為流失，整體流失率為 22%**。
- 月度趨勢圖顯示 **2023 年 3 月出現 50% 的單月高峰**，與多數月份約 5%–15% 的區間差異明顯，應優先確認是否為異常月份或資料定義造成。
- 圖表亦呈現 **2024 年下半年流失率逐步上升**的訊號，可作為進一步檢查客群、方案與客服體驗的切入點。
- 功能使用分析以「功能 × 客戶」去重，並比較使用者與未使用者的流失率，避免多筆使用紀錄造成重複計數。

## 結論與下一步

整體指標提供了流失規模，月度走勢則指出值得追查的時間區段；兩者都不能單獨解釋流失原因。下一步可結合國家、產業、訂閱方案、客服滿意度、工單處理效率及產品功能使用，檢視高流失率是否集中於特定客群，並將異常趨勢與資料口徑一併驗證，再提出可測試的留存策略。

> **解讀提醒：**不同分析視角使用的流失欄位與觀察期間可能不同，跨圖表比較前應先確認指標定義一致。功能使用與流失率的差異呈現的是關聯，不代表功能使用造成流失。
